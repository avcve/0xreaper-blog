About

I'm 0xReaper — an offensive security researcher and Web3 smart contract auditor. I write full-stack applications and I audit them, which means I test the way I actually think an attacker would build a mental model of the system, not just what a scanner flags.

Most of what's posted here comes out of real engagements. Client names, endpoints, tokens, and any personal data are always genericized or fabricated before publishing — the vulnerability class and the reasoning behind finding it are real, the specifics are not traceable to any client under NDA.

What I focus on

  • Access control and business logic flaws (the kind scanners miss)
  • Payment flow integrity — client-side tampering, gateway trust boundaries
  • Smart contract audits — access control, reentrancy, upgrade paths
  • API and web app security reviews
